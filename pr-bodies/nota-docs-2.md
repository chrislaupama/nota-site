Before: the favicon, hero icon and header logos drew the dial in Ember brass and warm browns.

After: the same dial is drawn in Studio colours, matching the recoloured app icon in chrislaupama/nota. The dark logo uses accent #FF9F1C, needle #F4F5F6 and track #2B2D31. The light logo uses accent #C46A00, needle #16171A and track #C9CBCF.

How: only the hex values in four SVGs changed (`public/favicon.svg`, `src/assets/hero-icon.svg`, `src/assets/logo-dark.svg`, `src/assets/logo-light.svg`). No site theme files were touched, so this doesn't overlap with the Studio docs restyle.
